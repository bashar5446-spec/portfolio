# Bashar Mohamad — Portfolio

A static portfolio with responsive project galleries. Open `index.html` to preview. No build step or external account is required to view it.

## Update content

- Edit `projects.js` to add or change projects. Place screenshots in `assets/` and list their paths, labels, and alternative text in the `images` array. A new project appears automatically.
- Fill in verified LinkedIn, GitHub or WhatsApp links in `PORTFOLIO_CONTACT`. Empty fields stay hidden.
- Edit biography and experience copy in `index.html`. Keep claims precise and private client details out of a public repository.
- The high-resolution screenshots are local assets; visitors do not need Notion. Images in the CRM section document a demo architecture.

## Publish with GitHub Pages

Create a public repository named `portfolio`. Upload the **contents** of this folder to its root. In Settings → Pages, choose Deploy from a branch → main → / (root). Commit later edits to `main` to update the website.
